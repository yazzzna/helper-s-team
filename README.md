# Helper’s Team TULA

Статический сайт с тремя интерактивными рулетками для команды помощников BLACK RUSSIA TULA. Используются HTML, CSS и JavaScript — сервер, Python и платный хостинг для публикации не нужны.

## Структура

```text
helpers_team_tula/
├── index.html
├── points.html
├── currency.html
├── gifts.html
├── css/style.css
├── js/main.js
├── js/points.js
├── js/currency.js
├── js/gifts.js
├── assets/
│   └── README.txt
└── README.md
```

## Как открыть локально

Можно просто открыть `index.html` в браузере. Для проверки удобнее запустить любой локальный статический сервер, но для обычного посещения сайта это не требуется. Не открывайте HTML через локальные абсолютные пути: все ссылки в проекте относительные и рассчитаны на GitHub Pages.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub, например `helpers-team-tula`.
2. Распакуйте архив и загрузите **содержимое папки проекта** в корень репозитория. В корне должны лежать `index.html`, `points.html`, `currency.html`, `gifts.html`, `css/`, `js/`, `assets/`.
3. Откройте репозиторий на GitHub → **Settings** → **Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве ветки выберите `main`, папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь завершения публикации. GitHub покажет ссылку вида `https://username.github.io/helpers-team-tula/`.
7. Откройте опубликованную ссылку и проверьте все три карточки. После обновления публикации может потребоваться небольшая пауза или жёсткое обновление страницы.

Если репозиторий называется `username.github.io`, адрес будет вида `https://username.github.io/`. Для обычного репозитория используется путь с названием репозитория. Все ссылки и ресурсы в проекте относительные, поэтому проект поддерживает оба варианта.

## Как добавить логотип

Поместите свой файл логотипа в `assets/logo.png`. На всех страницах уже предусмотрено место под логотип. Если `assets/logo.png` отсутствует, вместо него автоматически показывается аккуратная заглушка `HT`. Рекомендуемый формат — PNG с прозрачным фоном, квадратное изображение. Если хотите использовать другое имя файла, измените `src="assets/logo.png"` в HTML-файлах.

## Механики и важные ограничения

- **Рулетка баллов:** обычная — 35 баллов, диапазон 0–65; супер — 45 баллов, 0–90; мега — 55 баллов, 0–150. Используется экспоненциальное взвешивание: `weight = exp(-decay * (value - min))`. Чем больше значение, тем ниже его вес; все целые числа в диапазоне имеют ненулевой шанс.
- **Рулетка ИВ:** малая — 45 баллов, 100–10 000 ИВ; средняя — 55 баллов, 1 000–100 000 ИВ; большая — 65 баллов, 100 000–500 000 ИВ. Аналогичное взвешенное распределение с параметрами, настроенными отдельно для разных диапазонов.
- **Лимит ИВ:** две попытки сохраняются в `localStorage` браузера. Это ограничение действует только в конкретном браузере и на устройстве. Пользователь может сбросить его очисткой данных сайта, приватным окном или другим устройством. Для реального общего лимита «два раза на человека» нужен серверный бэкенд, хранилище и способ идентифицировать пользователя.
- **Рулетка подарков:** шесть призов с одинаковой вероятностью 1/6. Сектор сначала выбирается равномерно, а затем угол рассчитывается так, чтобы указатель остановился на выбранном секторе.
- **Безопасность:** результаты генерируются в браузере и не являются защищённой записью. Пользователь может изменить JavaScript или локальные данные. `Math.random()` достаточен для игровой симуляции, но не является криптографически защищённым источником случайности.
- **Стоимость и выигрыш:** в рулетке баллов и ИВ стоимость показана отдельно. Сайт не ведёт баланс и автоматически ничего не списывает.
- **Шрифты:** подключаются через Google Fonts; при недоступности сети используются системные запасные шрифты. Основные функции работают без сторонних библиотек.

## Настройка вероятностей

В `js/points.js` и `js/currency.js` у каждого типа рулетки есть параметр `decay`. Увеличение `decay` сильнее снижает вероятность крупных значений; уменьшение делает распределение более ровным. Функция генерации находится в `js/main.js` — `HelperRoulette.weightedInteger()`.

Список подарков находится в массиве `prizes` в `js/gifts.js`. При изменении списка необходимо оставить шесть элементов, если вероятность должна быть равной 1/6.

## Что проверено

Проект использует статические относительные пути, не требует сборки и не зависит от серверного Python. Скрипты проверяются на синтаксис при разработке; после публикации рекомендуется дополнительно проверить страницу в браузере на телефоне и компьютере, так как поведение зависит от браузера и его настроек хранения.
