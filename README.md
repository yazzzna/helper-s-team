# Helper’s Team TULA

Статический сайт с тремя интерактивными рулетками для команды помощников BLACK RUSSIA TULA. Работает на HTML, CSS и JavaScript без Python, сервера, сборки и платных сервисов.

## Содержимое проекта

- `index.html` — главная страница с тремя карточками.
- `points.html` — рулетка баллов.
- `currency.html` — рулетка игровой валюты.
- `gifts.html` — колесо подарков с шестью равновероятными секторами.
- `css/style.css` — оформление и адаптация под мобильные устройства.
- `js/main.js` — общие эффекты.
- `js/points.js` — логика рулетки баллов.
- `js/currency.js` — логика рулетки ИВ.
- `js/gifts.js` — логика колеса подарков.

## Логотип

В исходных материалах, приложенных к задаче, файла `logo.png` не было. Поэтому проект не подменяет его другим изображением: место под логотип предусмотрено в шапке, а если `logo.png` отсутствует, страница продолжит нормально работать. Добавь оригинальный файл `logo.png` в корень проекта рядом с `index.html`, `points.html`, `currency.html` и `gifts.html`. Относительный путь уже настроен: `./logo.png`.

## Как опубликовать на GitHub Pages

1. Распакуй ZIP-архив.
2. Войди в GitHub и создай новый репозиторий, например `helpers-team-tula`.
3. Нажми **Add file → Upload files** и загрузи содержимое папки проекта (не сам ZIP-архив).
4. Нажми **Commit changes**.
5. Открой в репозитории **Settings → Pages**.
6. В разделе **Build and deployment** выбери **Deploy from a branch**.
7. В качестве ветки выбери `main`, папку — `/(root)`, затем нажми **Save**.
8. Подожди завершения публикации. Адрес сайта появится в разделе Pages; обычно он имеет вид `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Никакие пути не привязаны к корню домена: внутренние ссылки используют относительные пути, поэтому сайт должен работать и в репозитории GitHub Pages с подпутём.

## Как настроить вероятности

### Баллы и ИВ

Открой `js/points.js` или `js/currency.js` и найди функцию `weightedInteger`. Сейчас вес каждого числа рассчитывается по формуле:

`1 / (1 + (доля диапазона / 0.58)^1.7)`

Меньшее значение степени делает распределение более ровным, а большее сильнее увеличивает частоту небольших выигрышей. Параметр `0.58` задаёт область, в которой вероятность начинает заметнее снижаться. Все числа в указанном диапазоне сохраняют ненулевой вес. Максимумы и стоимость рулеток вынесены в объект `modes` в начале соответствующего файла.

### Подарки

В `js/gifts.js` список призов хранится в массиве `prizes`. Индекс выбирается выражением `Math.floor(Math.random() * prizes.length)`, поэтому все шесть вариантов имеют одинаковую вероятность. Не добавляй отдельные веса, если хочешь сохранить равные шансы.

## Важные детали

- Количество прокруток не ограничено; счётчиков попыток и блокировок по числу запусков нет.
- Сайт не списывает баллы и не выдаёт валюту или игровые награды на сервере — он только показывает случайный результат в браузере.
- Пока идёт анимация, повторный запуск отключён, после завершения кнопка снова активна.
- Все ресурсы — локальные файлы проекта; внешний сервер не требуется.
